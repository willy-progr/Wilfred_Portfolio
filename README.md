## Project layout

- **`app/`** — Next.js app (source, `package.json`, and full developer docs in [`app/README.md`](app/README.md))

## Quick start

```bash
cd app
npm ci
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
cd app
npm run build
```

Static export output: `app/out/` (used by Cloudflare Pages).
